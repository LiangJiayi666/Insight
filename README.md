# 见微 · Insight Daily

一份关注经济、金融、社会与政治的每日简报。

见微不只整理“发生了什么”，也尝试解释变化如何传导、影响谁，以及接下来值得观察什么。用具体的企业、家庭情境和简单算例，把新闻与日常生活连接起来。

## 阅读方式

打开页面先看到新闻标题，感兴趣再展开。

每条新闻按层次组织：

- **事实概览**：发生了什么，涉及哪些群体。
- **具体实例**：通过企业案例、生活情境或账目理解抽象概念。
- **影响分析**：梳理原因、传导过程和成立条件。
- **背景关联**：补充前置事件、历史经验与可比较的案例。
- **后续观察**：哪些数据和进展值得继续跟踪。
- **原文来源**：保留出处、日期及参考摘录，方便回看。

界面采用粉紫色纯色配色，保留清晰的内容层次，不使用渐变。支持手机与桌面阅读，也能打包成包含样式和交互的单个 HTML 文件。

## 每日流程

```text
检索新闻与背景资料
        ↓
筛选不同事件，整理来源与解读
        ↓
校验稿件，生成 HTML，按日期归档
        ↓
飞书发送日报附件与用量台账
        ↓
同步 GitHub，备份与清理运行数据
```

每日以 **12 个不同事件**为目标，不用重复报道或旧闻补足数量。

新闻研究与写作由 Pi 执行，程序负责结构校验、引文匹配、页面生成、归档和发送。内容优先采用官方发布与主流媒体报道，事实、分析和假设情境在表达上保持区分。

## 日报与台账

每天 22:00 自动发送日报和用量台账，也可以通过飞书发送 **“日报”** 获取同样的内容。

当天尚未出刊时，附上昨天的日报并注明日期。用量台账统计当天制作与测试中可观测的输入、输出、缓存 token，以及搜索和网页读取次数；无法确认的费用不按零计算。

## 文件组织

| 路径 | 内容 |
| --- | --- |
| `public/index.html` | 最新日报页面 |
| `public/issues/` | 按年、月、日归档的历史日报 |
| `data/issues/` | 结构化稿件与来源信息 |
| `src/` | 制作流程、附件打包、台账与同步逻辑 |
| `scripts/` | 生成、预览与维护任务入口 |
| `styles.css`、`app.js` | 页面样式与展开交互 |
| `tests/` | 自动化测试 |
| `docs/` | 实现与维护记录 |
| `archive/` | 早期原型与试刊 |

仓库保存项目代码、日报页面与结构化稿件。凭证、私有运行日志、消息投递记录和本地备份不纳入版本管理。

## 技术组成

- **Pi**：新闻检索、资料阅读与稿件整理。
- **Node.js**：流程编排、校验、文件管理与静态页面生成。
- **HTML / CSS / JavaScript**：以原生 `details` 实现逐层展开，无前端框架。
- **飞书自建机器人**：指令接收与日报、台账发送。
- **Windows 任务计划程序**：每日制作和维护调度。
- **Git**：保存代码与日报版本，自动同步仓库。
