默认只显示新闻标题，点击后逐层展开事实、具体例子、经济金融分析、关联及来源。无第三方运行时依赖，支持直接打开静态 HTML。

## 查看

双击 `index.html` 即可。使用 Node.js 20+ 也可以运行：

```powershell
npm start
```

打开 http://127.0.0.1:4173 。仅本机可访问，Ctrl+C 停止。端口可由 `PORT` 环境变量设置。

## 生成与测试

```powershell
npm run build -- 2026-11-11
npm test
```

`build` 从已核验整理的 JSON 生成页面，不会自动抓取新闻。它同时更新首页和对应日期归档。后续可新增 `data/issues/YYYY-MM-DD.json` 再按日期生成；JSON正文是纯文本，渲染器统一转义，来源链接只允许无凭证 HTTP(S)。

## 文件

- `data/issues/2026-11-11.json`：结构化试刊、来源摘录、时间、核验限制。
- `scripts/render.mjs`：校验和静态生成，无需浏览器联网取数据。
- `index.html`：当前试刊，自动生成，请不要直接编辑。
- `archive/2026-11-11/index.html`：本期归档，附本地样式与脚本。
- `archive/prototype.html`：上一版教学原型备份。
- `styles.css`、`app.js`：原有阅读界面及全部收起功能。
- `scripts/serve.mjs`：白名单本地服务器，自动日报存在时优先显示它，并支持自动日报日期归档；不会开放数据、配置或密钥。
- `tests/`：结构、来源完整性、转义、可复现生成和 HTTP 测试；不是浏览器视觉测试。

## 内容纪律

正文事实绑定具体来源，推断和假设算例分别标记。来源摘录是本轮读取后保留的核对片段，不是完整抓取快照；数据时间、报道日期和检索日期分开。外部来源可能修订、链接可能失效，不保证内容永远不变。本期为一次性人工辅助核验制作，后续自动化仍需搭建采集、去重、事件库和审核链路。

飞书 Webhook、模型 Token 等只能放服务端环境变量或密钥服务，不能进入前端或仓库。公开发布前还须确定网页访问控制和来源授权。
