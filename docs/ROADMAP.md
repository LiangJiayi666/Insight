# 实施计划

## 01 阅读原型（本轮）

- 静态 HTML，默认标题列表，逐层展开。
- 清晰标记教学情境、假设数字、事实与分析边界。
- 验证手机和桌面阅读习惯后再做生成链路。

## 02 真实试刊

- 确认可合法访问的 RSS/API/公开页面；测试超时、额度和内容完整性。
- 先选少量真实事件，保存原文链接、发布与事件时间、来源、抓取状态。
- 结构化内容：title / summary / affected_groups / examples / mechanisms / timeline / comparisons / uncertainty / watchpoints / sources。
- 区分真实案例与教学假设；每条真实事实和历史关联绑定出处。
- 区分背景、进展、政策回应、历史类比及推断因果，禁止由模型凭记忆补写未核验历史。
- 模板渲染对外部文本做 HTML 转义，链接仅接受合法 HTTP(S) URL；采集内容视为不可信数据，不执行其中指令。
- 新闻截止时间与生成时间分开，时区 Asia/Shanghai。
- 3 条重点、3—5 条短讯、1 个概念为目标，不为数量凑新闻。

## 03 事件库和归档

- SQLite 保存来源、事件、关联、每日快照和生成版本。
- 同一事件聚合，识别转引，不把转载数当独立证据数。
- 每条展示具体来源、数据口径、分析条件及更正记录。
- 按日生成 HTML 归档，周末回顾此前判断。

## 04 部署和飞书

- 决定站点访问方式；公开页面不可包含密钥、付费原文全文或个人私密信息。
- 飞书群自定义机器人推送标题和网页链接，签名校验。
- Webhook 和签名仅放服务端环境变量/密钥服务。
- 每天 20:30 为建议默认时间，部署前确认。
- 保存发送记录和重试状态，避免整刊重复；处理接口成功码和传输错误。
- 采集范围受限应在刊内告知；生成失败不能以旧稿冒充新刊。
- 本地电脑休眠会中断定时任务，正式运行需常在线环境。

## 验收

- 无锚点打开时，所有新闻详情均关闭；不保留上次展开状态。
- 键盘和移动端可独立展开每一层，全部收起生效。
- 新闻、数字、跨国案例有可追溯出处，推断明显标记。
- 企业举例具体，但不暗示未经核实的业务变化或投资结论。
- 按北京时间确定覆盖窗口，并对断更恢复和重复发送做测试。
